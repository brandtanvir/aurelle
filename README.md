# Aurelle · Private Aviation

> **Concept project.** Aurelle is a fictional brand made as a UI/UX portfolio piece. It is not an airline or charter operator; ratings, certificates, prices and contact details are illustrative and the forms send nothing.

**Live site:** https://brandtanvir.github.io/aurelle/ · **Case study:** [case-study/Aurelle-Case-Study.pdf](case-study/Aurelle-Case-Study.pdf)

An immersive marketing site for a private jet operator: charter, jet card membership and empty legs. Sky-blue and white palette, DM Sans throughout (self-hosted in `fonts/`, OFL), real in-flight footage.

- Strategy, feasibility, UX research and PRD: [docs/STRATEGY.md](docs/STRATEGY.md)
- Sitemap and user paths: [docs/SITEMAP.md](docs/SITEMAP.md)

## Run locally

```bash
python3 serve.py 5200
```

Then open http://127.0.0.1:5200. No build step. Libraries load from pinned CDNs: GSAP 3.12.5, ScrollTrigger, Lenis 1.1.13, Three.js r169.

## Structure

| File | What it does |
|---|---|
| `index.html` | All sections and the booking dialog |
| `css/style.css` | Design tokens (sky blue & white), layout, responsive rules |
| `js/main.js` | Smooth scroll, reveals, nav, fleet stepping, membership calculator, planner, empty-legs board, intro |
| `js/jet.js` | The procedural 3D business jet (fallback for the fleet viewer) |
| `media/` | Web-encoded stock footage: hero (also used for Contact) and four experience chapters, each with a portrait cut for phones and a poster frame |
| `assets/earth-night.jpg` | NASA Earth Observatory “Black Marble” (public domain), used by the globe |
| `js/fleet.js` | Turntable fleet viewer that morphs between aircraft classes; loads `assets/jet.glb` when enabled |
| `js/globe.js` | Night Earth with atmosphere, light-trail route and city labels (loaded lazily) |
| `js/booking.js` | Four-step quote request with airport autocomplete and indicative pricing |
| `js/data.js` | Airports, fleet specs (incl. cabin dimensions and typical routes per class), empty legs, distance/flight-time maths |
| `fleet/*.html` | One page per class: 3D hero, specification, cabin floor plan, typical routes, request. Generated by `tools/build-fleet-pages.py` |
| `js/aircraft.js` | Script for the aircraft pages; reuses the fleet model loader, booking overlay and flight-time maths |
| `js/floorplan.js` | Top-down cabin plans (indicative layouts in metres), drawn as SVG |
| `js/theme.js` | Palette values shared with the WebGL scenes |
| `safety.html`, `privacy.html`, `cookies.html`, `terms-of-carriage.html`, `operator-disclosure.html` | Trust and legal pages. Entities, addresses, certificate numbers, audit dates and fees are fictional demo content |
| `css/pages.css`, `js/page.js` | Shared layout and script for those sub-pages (nav, menu, footer; no WebGL). Their footer is a copy of the homepage footer, so change both together |
| `css/consent.css`, `js/consent.js` | Cookie consent on every page: essential only by default, reject as easy as accept, choice kept in localStorage for 12 months, Global Privacy Control honoured. Load analytics only inside `whenAllowed('analytics', …)` |

## Aircraft pages

`fleet/light.html`, `midsize.html`, `ultra-long-range.html` and `flagship.html` share their nav, menu, footer and booking overlay with `index.html`. After changing any of those on the homepage, or the per-class copy in the script, regenerate them:

```bash
python3 tools/build-fleet-pages.py .
```

Specs and route times come from `FLEET` in `js/data.js`; cabin layouts from `PLANS` in `js/floorplan.js`.

## 3D fleet models

Each class in `FLEET` (`js/data.js`) names a `glb`. Both files were optimized with gltf-transform (WebP textures at 1024 px, simplified, meshopt-compressed):

| File | Source | License | Size |
|---|---|---|---|
| `assets/jet.glb` | “Bombardier Learjet 45” by KarimFatatry (Sketchfab) | CC BY 4.0 | 1.4 MB (was 120 MB; hidden interior removed, hull set opaque) |
| `assets/jet-black.glb` | “Private jet black” by pmglobalmarketinginfo1 (Sketchfab) | CC BY 4.0 as listed, but see the note below | 0.3 MB (was 25.7 MB); rendered in pearl white by a texture-remap shader |

Credits show in the footer automatically. Per-file orientation fixes are in `MODEL_FIX` in `js/fleet.js`. If a file is missing, the procedural jet is shown instead.

**Note on the black jet:** its file name (`uploads_files_2139909…`) follows CGTrader's naming, which suggests a re-upload of a marketplace model. Confirm the uploader had the rights before launch, or point Ultra-long-range and Flagship at `assets/jet.glb`.
**Not used:** “Bombardier Learjet 60” is CC BY-NC-SA (non-commercial only).

## Before going live

- Connect the footer's empty-leg alerts form to a mailing-list provider (hook marked in `js/main.js`).
- Replace placeholders: phone `+44 20 0000 0000`, `concierge@aurelle.example`, WhatsApp link.
- The trust and legal pages, and the footer accreditations, use fictional companies, addresses, certificate numbers and audit dates. Before any real launch, replace them with the operator's actual details and have counsel review the text.
- If no analytics will be installed at launch, set `ASK = false` in `js/consent.js` so the banner stays hidden; the Cookies page still offers the setting.
- Wire the booking form to email or a CRM. The hook is marked in `finish()` in `js/booking.js`.
- Confirm hourly rates, aircraft specs and empty legs with operations. All figures are indicative.
- Self-host fonts and libraries if you need to avoid CDNs.
- Confirm the stock footage licence (Pexels-style clips allow commercial use; keep the source records).
